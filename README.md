# Gamefolk

Личный дневник людей из игр и историй с ними: кто это, как познакомились, ники в разных играх, общие истории и скриншоты.

## Как открыть

1. Скачай файл `gamefolk.html`.
2. Открой его двойным кликом. Удобнее всего в Chrome, Edge или Яндекс Браузере.

Интернет не нужен. Сайт не отправляет никуда ни одного запроса: это запрещено самой страницей.

## Где хранятся данные

- Все записи и картинки лежат только в этом браузере, в его хранилище (IndexedDB).
- Они всегда зашифрованы (AES-256-GCM). Ключ создаётся при первом запуске.
- **Код на вход** (раздел «Данные») защищает записи от тех, у кого есть доступ к компьютеру. С ним сайт спрашивает код при открытии и блокируется после бездействия.
- **Ключ восстановления** показывается при первом запуске. Он открывает записи, если забыть код. Храни его не на этом компьютере.

Как не потерять записи:

- **Бэкап** (раздел «Данные»): зашифрованный файл `.gamefolk`. Открывается только ключом восстановления, поэтому хранить его можно где угодно. Сайт напомнит, если бэкапа не было неделю.
- **Синхронизация**: вход через Google, записи на всех устройствах. Работает, когда сайт открыт по адресу в интернете (как выложить: [docs/DEPLOY.md](docs/DEPLOY.md)). Новое устройство подключается кодом, подтверждённым со старого, или ключом восстановления. На сервер уходит только шифр.
- **Выгрузить всё**: zip-архив, который открывается и без Gamefolk: книга воспоминаний, JSON, истории текстом и картинки.

## Что умеет

- Лента историй: поиск по тексту, людям и никам, фильтры по игре, человеку, тегу и году, сортировка, избранное.
- История: кто был (люди из списка, просто имена и случайные игроки), название, текст, игра, теги, точная или примерная дата, до 6 картинок, черновик сохраняется сам.
- Человек: фото, имя, свой статус, игры, ники в играх, контакты, как познакомились, заметка, все общие истории.
- Удаление с кнопкой «Отменить».
- Приветствие по имени, блок «В этот день», живые анимации (отключаются, если в системе включено «уменьшить движение»).
- Русский и английский, тёмная и светлая тема, удобно с телефона.
- Горячие клавиши: `N` новая история, `/` поиск, `Esc` закрыть окно.

## Для разработки

Нужен Node.js 20 или новее.

```bash
npm install
npm test         # автотесты
npm run build    # собирает gamefolk.html
```

Устройство проекта описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
